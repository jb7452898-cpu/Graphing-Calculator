
This is for a graphing calculator

Expressions can be entered and lines or curves are graphed

if there is a problem expression to be solved, you can enter it in the problem box and try to solve it in the workspace below

any solvable expressions that are equivalent to themselves will be shown with a check 

can be used for multi variable linear equations 

can be used for quadratic equations

if the solution matches the input problem, there will be a message confirming
